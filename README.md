## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. In the left sidebar, select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish deploying. The site URL should appear on the Pages settings screen.

Official guide: https://docs.github.com/en/pages/quickstart

## Portfolio accuracy

This site is a living portfolio. Project summaries are intentionally high-level while dates, metric definitions and supporting evidence are being verified. Planned product features must not be described as launched. Private analytics, client information and immigration documents should not be committed to this public repository.
